# 文案四阶盲审复核操作规程 (Audit Protocol)

本规范定义了商业文案与视频脚本交付前，必须执行的“四阶盲审复核流程”。每一阶对应不同的审校视角与淘汰标准，全部通过后方可定稿交付。

---

## 第一阶：耳朵盲听审查 (The Blind Listening Pass)

### 1. 核心目标
测试文本是否符合人类听觉的生理接收极限（工作记忆与语音回路），确保听觉“零阻力、无衰减”。

### 2. 操作方法
* **工具**：使用文本转语音（TTS）或由另一人以自然语速朗读；
* **测试者动作**：**闭上双眼，双手离开鼠标键盘，不看文字稿**，全程仅用耳朵接收；
* **标记机制**：朗读过程中，一旦产生以下三种感受之一，立刻叫停：
  1. *“刚才念的这半句是什么意思？”*（说明信息过密或抽象大词导致了听觉卡顿）；
  2. *“怎么感觉嘴巴打架、读得有点别扭？”*（说明有同音叠词或动宾语病）；
  3. *“感觉念得快喘不上气了”*（说明缺少气口，单句过长）。

### 3. 一票否决项
* 单个句子不带标点超过 28 个汉字；
* 出现同字/同音字相隔不足 4 个字（如“一个人的一人公司”）；
* 动宾搭配违反口语生活习惯（如“通畅健康”、“赋能生活”）。

## 第二阶：杠精防御者审查 (The Cynical Auditor Pass)

### 1. 核心目标
激活“反营销免疫系统 (PKM)”，从一个对商业推销极度防备、受过市场伤害的挑剔客户视角，排查所有可能引发反感、怀疑和自嗨的文案。

### 2. 审查员心智模型 (Persona)
> *“我是一个做过生意的老江湖，见过无数跑路吹牛的平台，我警惕性极高，最讨厌别人给我画大饼、自我感动、跟我套近乎。你说什么我都先打个问号。”*

### 3. 逐句拷问清单
| 文案内容 | 杠精审查员的第一反应 | 处理规则 |
|---|---|---|
| “我们的初心很纯粹” | *“你纯不纯粹关我屁事？无事献殷勤，你急着表白是不是想骗我？”* | **立删**，换成具体平台搭建动作。 |
| “我们倾尽心血” | *“你倾尽心血说明你水平不行效率低，我只关心产品好不好。”* | **立删**，换成严谨的研发标准与批文。 |
| “市面上很多都是假冒贴牌” | *“又开始搞拉踩同行那一套了，心胸狭隘，你以为你多高尚？”* | **立改**，换成大众对更高品质的正向期待。 |
| “我们是真诚的连接” | *“每个割韭菜的都说自己真诚，真正的真诚不用嘴巴说。”* | **立改**，删除“真诚”，陈述业务沉淀的事实。 |
| “极致的产品力” | *“到底有多极致？吹牛不打草稿，谁信？”* | **立改**，换成“过硬的产品力”或“药企品控底盘”。 |

## 第三阶：法务与合规红线扫描 (The Compliance Red-Line Scan)

### 1. 核心目标
排除广告法违规风险、民商事合同隐性承诺风险、战略合作虚假陈述风险。

### 2. 扫描矩阵
```
┌────────────────────────────────────────────────────────┐
│                   合规审查三大警戒区                    │
├────────────────────┬───────────────────┬───────────────┤
│ 1. 绝对化承诺区    │ 2. 商业名分混淆区 │ 3. 功效虚标区 │
│   - 兜底           │   - 战略合作协议  │   - 包治百病  │
│   - 不用操心       │     (未盖章禁用)  │   - 彻底根除  │
│   - 稳赚不赔       │   - 深度绑定      │   - 药到病除  │
│   - 终身保障       │   - 旗下独家      │   - 纯天然无毒│
└────────────────────┴───────────────────┴───────────────┘
```

### 3. 执行规范
* **承诺降维**：凡涉及效果与责任承诺，全部降维为**能力赋能、系统培训、坚实支撑**；
* **合作定性**：
  * 已签署《战略合作协议》 $\rightarrow$ 可使用“战略合作伙伴”；
  * 未签署正式战略协议但有供货或深度业务往来 $\rightarrow$ **统一降级使用“携手”、“战略深耕”**；
  * 拒绝使用“背靠”等非规范法律用语（具依附感且缺乏权责界定）。

## 第四阶：视听节拍与音画对应测试 (The Metronome & B-Roll Match)

### 1. 核心目标
确保文案不仅是一段好文章，更是一份**能被摄像机镜头完整承载的视听脚本**。

### 2. 节拍器公式
* 正常抒情/叙事语速：**3.4 ~ 3.6 字/秒**（即每 10 秒念 35 字左右）；
* 一个镜头画面的黄金停留时间：**2.5 ~ 4 秒**。

### 3. 音画匹配度检查表
1. **画面具象性**：念到这句话时，剪辑师是否能立刻从素材库找到对应的 B-Roll 画面？
   * *反例*：“我们致力于打破时代的不确定性”（剪辑师抓狂：抽象概念无法配图，只能放空镜）。
   * *正例*：“人体十万公里的血管河道默默承受淤堵”（剪辑师立刻可配：血管微循环 3D 动画或显微镜头）。
2. **节奏留白**：重要转折、数据亮出后，是否留有 0.5~1 秒的音乐垫乐？
3. **情绪定格**：全片终局的金句念出时，画面是否能在 2 秒内利落定格 Logo，且音效干净收束？
